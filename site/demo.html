Take the next step

Try the running demo.

With Node.js 24 or newer, start the app with its sample data. No game server or running database is needed for demo mode. 

git clone https://github.com/oddessentials/magpie.git
cd magpie
npm install
npm run dev:mock

Open the local address printed by the command. Browse the adventurers, filter the journal and explore the world. Demo admin changes are simulated.
